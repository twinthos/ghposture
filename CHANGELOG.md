# Changelog

## 1.0.0

First release.

- 19 checks: 10 repository settings, 9 workflow supply-chain.
- Text, Markdown and JSON output; deterministic ordering.
- Coverage ledger that separates checked, passed and skipped.
- Expiring baselines for accepted risks.
- Read-only, standard-library HTTP client with timeouts, retries and no token logging.
- 28 tests, no network access in the suite.
